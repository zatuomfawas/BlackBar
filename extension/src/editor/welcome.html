02

Black bars only

Blur and pixelation are in the toolbar because people expect them, but neither is redaction — pixelated text has been reconstructed by researchers for years, and blur leaks more than it hides.

Only a black bar counts toward clear in the status line. Every export is flattened, so a bar is deleted pixels rather than a layer someone can lift off, and re-encoding drops the image metadata on the way out.

03

Don't take our word for it

// manifest.json
"content_security_policy": {
  "extension_pages": "connect-src 'none'"
}

Chrome itself refuses to let this extension open a connection. That isn't a promise we're making, it's a rule enforced on us. Four ways to check it in under a minute:

  1. Turn off your Wi-Fi. Everything still works.
  2. Open DevTools → Network, then capture. Nothing appears.
  3. Watch the status bar — the editor runs the test itself on every open.
  4. Read the source. There's no build step, so the package is the repository.

04

What it can't do

Chrome blocks every extension from reading its own pages, so nothing can capture the New Tab page, Settings or the Web Store. Use your system screenshot key and paste the image straight into the editor instead.

Blackbar reads text from the page, so it can't read text inside images, video or a <canvas>. It flags those regions as unreadable rather than implying they're clean. It doesn't detect faces, and it won't guess which words are someone's name — a detector that's wrong half the time teaches you to ignore it.

Treat detection as a second pair of eyes. Yours are still the first.
